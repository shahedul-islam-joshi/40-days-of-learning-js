## 🛠️ Development Setup

### Prerequisites
- Node.js (v14+)
- A code editor (VS Code recommended)
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git & GitHub account

### How to Run Examples

1. Clone this repository:
   ```bash
   git clone https://github.com/shahedul-islam-joshi/40-days-of-learning-js.git
   cd 40-days-of-learning-js
   ```

2. Navigate to a specific day's folder:
   ```bash
   cd day-01
   ```

3. For HTML/JavaScript examples, open the `.html` file in your browser:
   ```bash
   # On Windows
   start index.html
   
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   ```

4. For Node.js scripts, run with:
   ```bash
   node test-script.js
   ```

## 📝 Day 1: Introduction & Setup

**Topic:** Setting up JavaScript development environment and first program

**What I Learned:**
- How to set up an HTML file with JavaScript
- Using `console.log()` for output
- DOM selection with `document.getElementById()`
- Manipulating element content with `innerText`

**Code Example:**
```javascript
// test-script.js
console.log("It's a test script!");
document.getElementById("someId").innerText = "It's some div.";
```

**HTML Structure:**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <h1>Welcome to JS world!</h1>
    <div id="someId"></div>
    <script src="./test-script.js"></script>
</body>
</html>
```

## 📖 Quick Reference

### Console Commands
```javascript
console.log()      // Print to console
console.error()    // Print errors
console.warn()     // Print warnings
console.table()    // Display data as table
```

### DOM Selection
```javascript
document.getElementById()      // Select by ID
document.querySelector()       // CSS selector
document.querySelectorAll()    // All matching elements
```

### Common Methods
```javascript
innerText          // Get/set element text
innerHTML          // Get/set element HTML
classList.add()    // Add CSS class
addEventListener() // Add event listener
```
