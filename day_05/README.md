# Day 06 — Loops & Logic Building

Part of the **40 Days of JavaScript** challenge by tapaScript.

## What I Practiced

- `for` loop — when we know exactly how many times to iterate
- `while` loop — when iteration count is unknown in advance
- `do-while` loop — guarantees code runs at least once before checking condition
- `break` and `continue` — controlling loop flow
- Nested loops — loops inside loops (used for pyramid pattern)

## Key Takeaways

- Use `for` when the number of iterations is known
- Use `while` when looping on a condition
- Use `do-while` when the code must run at least once
- `%` (modulo) is useful beyond even/odd — it extracts digits too
- Nested loops multiply iterations: outer × inner
